Foundation Math: Cycle 1 (installable app)

1. Put ALL files of this folder on any free website host that gives you an https link
   (for example Netlify Drop or GitHub Pages). Keep the files together.
2. Open the link on your phone.
   Android Chrome: menu, then Install app (or Add to Home screen).
   iPhone Safari: Share, then Add to Home Screen.
3. After the first visit the app works offline.

Safety: no outside scripts, a strict Content-Security-Policy, and progress and API keys stay on the device.
To update the app later, upload the new files and change 'fm-v1' in sw.js to 'fm-v2'.
